# Useful Facts

A small zine of short, checked lessons on useful things to know: metacognition, cognitive bias, decision-making, financial education, procrastination, neuroplasticity, epigenetics, geopolitics, and clear thinking.

The home page is a corkboard of pinned sticky notes on a light orange-beige ground, with tangerine accents and butter-yellow paper. Lessons read as a magazine story, with "Did you know?" pull quotes, a Myth vs Fact toggle on flagged claims, and a flip-and-stamp quiz. Inspired by an [Instagram carousel by @explain](https://www.instagram.com/p/DfdGsSdn7iM/) about Ad Astra.

Progress is stored in the browser. Use Backup / restore to move it to another device.

Live: https://lilyofthevalley1618.github.io/useful-facts/
