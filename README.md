# Useful Facts

A small practice site with short lessons on useful things to know: metacognition, cognitive bias, decision-making, financial education, procrastination, neuroplasticity, epigenetics, geopolitics, and clear thinking.

The home screen is a dark card gallery with SVG topic icons and a progress ring. Facts are swipeable, story-style cards. Inspired by an [Instagram carousel by @explain](https://www.instagram.com/p/DfdGsSdn7iM/) about Ad Astra. Lessons use original wording; overstatements are flagged.

Progress is stored in the browser. Use Backup / restore to move it to another device.

Live: https://lilyofthevalley1618.github.io/useful-facts/
