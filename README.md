# Useful Facts

A small zine of short, checked lessons on useful things to know, plus Geography practice and a linked mystery.

The home page is a corkboard of pinned sticky notes on a light orange-beige ground, with tangerine accents and butter-yellow paper. Each lesson has a clear explanation, researched real-life examples, and a short self-test quiz with a saved score.

Geography is organized by continent, with U.S. States as its own always-open choice. Maps are fitted to the region you pick; +/− and Fit zoom in and out, clamped so you cannot shrink smaller than the fitted view. A step-by-step path (90% to unlock the next place) and a full-region test sit side by side. Optional Challenge practice remains. Passing steps and high test scores open folders in the Mystery tab, an original case file called *False North*.

Maps are bundled public-domain data (Natural Earth via world-atlas, U.S. Census via us-atlas). Progress is stored in the browser. Use Backup / restore to move it to another device.

Live: https://lilyofthevalley1618.github.io/useful-facts/
