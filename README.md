# Useful Facts

A small, calm practice site with short lessons on useful things to know: metacognition, cognitive bias, decision-making, financial education, procrastination, neuroplasticity, epigenetics, geopolitics, and clear thinking.

It was built from an [Instagram carousel by @explain](https://www.instagram.com/p/DfdGsSdn7iM/) about Ad Astra, Elon Musk's 2014 school. The site teaches those topics with original wording. Claims were checked, and overstatements (including the idea that the eight topics were a documented official Ad Astra syllabus) are flagged in the lessons.

Progress is stored in the browser. Use Backup / restore to move it to another device.

Live: https://lilyofthevalley1618.github.io/useful-facts/
