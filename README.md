# Useful Facts

A small zine of short, checked lessons on useful things to know, plus a Geography tab for practicing world countries and U.S. states.

The home page is a corkboard of pinned sticky notes on a light orange-beige ground, with tangerine accents and butter-yellow paper. Lessons read as a magazine story. Geography uses bundled public-domain map data (Natural Earth via world-atlas, U.S. Census via us-atlas): learn by tapping the map, then practice with Find it and Name it.

Progress is stored in the browser. Use Backup / restore to move it to another device.

Live: https://lilyofthevalley1618.github.io/useful-facts/
