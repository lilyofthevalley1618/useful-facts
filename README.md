# Useful Facts

A small zine of short, checked lessons on useful things to know, plus a Geography tab.

The home page is a corkboard of pinned sticky notes on a light orange-beige ground, with tangerine accents and butter-yellow paper. Lessons read as a magazine story. Geography is a step-by-step path: one major country (or a well-known U.S. state) at a time, on a zoomed-in map, with a short 90% quiz to unlock the next. Find it and Name it remain as an optional Challenge. Maps are bundled public-domain data (Natural Earth via world-atlas, U.S. Census via us-atlas).

Progress is stored in the browser. Use Backup / restore to move it to another device.

Live: https://lilyofthevalley1618.github.io/useful-facts/
