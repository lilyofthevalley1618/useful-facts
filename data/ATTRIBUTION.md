# Map data and libraries

Country boundaries are from Natural Earth (public domain), via the
[world-atlas](https://github.com/topojson/world-atlas) package (ISC,
Copyright 2013-2019 Michael Bostock), file `countries-50m.json`
(Natural Earth Admin 0, 1:50m).

U.S. state boundaries are from the U.S. Census Bureau Cartographic
Boundary Files (public domain), via the
[us-atlas](https://github.com/topojson/us-atlas) package (ISC,
Copyright 2013-2019 Michael Bostock), file `states-10m.json`.

Projection and topology helpers: [d3-geo](https://github.com/d3/d3-geo)
and [topojson-client](https://github.com/topojson/topojson-client)
(ISC, Copyright Mike Bostock).

Made with Natural Earth. Free vector and raster map data @ naturalearthdata.com.
